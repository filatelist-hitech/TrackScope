# Project Bootstrap

1. Inspect the existing tree before writing files.
2. Preserve working DSP tests and docs.
3. Create missing directories with README or `.gitkeep` when they are intentionally empty.
4. Keep Phase 0/1 work DSP-first; do not create fake mobile BPM behavior.
5. Update `README.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, and `docs/QA_MATRIX.md` when boundaries change.
6. Run available validation commands and report gaps.
