# Project Bootstrap Skill

When this skill is active:

1. Inspect existing repository structure.
2. Create or update the root project layout.
3. Do not implement deep features yet.
4. Create docs first:
   - README.md
   - docs/ARCHITECTURE.md
   - docs/ROADMAP.md
   - docs/QA_MATRIX.md
5. Create placeholder modules with clear contracts.
6. Add build/test commands only if they actually work.
7. Final answer must include:
   - created files
   - project tree
   - next implementation task
