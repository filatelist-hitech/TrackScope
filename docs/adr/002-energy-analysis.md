# ADR 002: Energy Analysis Algorithm

## Status: Proposed

## Date: 2026-06-01

## Context

Нужен энергетический уровень 1–10 (Mixed In Key стиль) в реальном времени. Цель:
- Помочь DJ отслеживать «энергетический arc» сета.
- Дополнить BPM и Camelot в Setlist Tracker.
- Быть ненулевым и осмысленным на hitech-материале.

## Decision

**RMS + spectral flux + onset density → взвешенная сумма → квантизация 1–10.**

Компоненты:

| Компонент | Вес | Источник |
|---|---|---|
| RMS dBFS (скользящий 3 сек) | 40% | `input_level_dbfs` уже в DspResult |
| Spectral flux (среднее за горизонт) | 35% | Уже вычисляется в onset-пайплайне |
| Onset density (онсетов/сек) | 25% | Из `onset_history` в DspEngine |

Нормализация каждой компоненты: [0, 1] через калиброванные мин/макс на hitech-материале (datasets/hitech/).

## Consequences

- **Переиспользование:** все три компоненты уже вычисляются в `DspEngine`; `EnergyAnalyzer` читает их напрямую без дублирования.
- **Нет лишних STFT:** энергия вычисляется поверх уже имеющихся данных.
- **Калибровка:** константы нормализации требуют обучения на реальных треках — задача Phase 2.
- **Ограничение:** в тишине и шуме energy = 0 (не 1); на брейкдауне просядет.

## Файлы

`core/dsp/src/energy_analyzer.rs` (Phase 1 skeleton готов, Phase 2 — реализация).
