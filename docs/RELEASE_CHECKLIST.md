# Релизный чеклист

## DSP

- BPM вычисляется из аудио/онсетных данных.
- Уверенность считается из evidence, а не хардкодится.
- Raw- и нормализованные кандидаты сохранены.
- Hitech-нормализация покрыта тестами.
- Тишина и шум-без-сигнала не дают `STABLE`.
- Клиппинг детектируется и подавляет чрезмерно уверенный выход.

## Mobile

- Разрешение микрофона корректно обрабатывается на Android и iOS.
- Аудио-callback не блокируется.
- Flutter не считает BPM напрямую.
- Живой UI показывает BPM, уверенность, состояние захвата и предупреждения о клиппинге.
- Отладочный экран показывает BPM-кандидатов и качество сигнала.

## Тесты

- Синтетические BPM-тесты проходят для 170, 180, 190, 200 и 220 BPM.
- Half-time и double-time ловушки покрыты.
- Тишина, белый шум, розовый шум, клиппинг микрофона, брейкдаун и плотный hitech-бас покрыты фикстурами.
- Контрактные тесты Rust DSP проходят.
- Offline-lab CLI выдаёт задокументированный JSON-контракт.

## Документация

- Архитектура актуальна.
- Заметки по DSP-алгоритму актуальны.
- Задержка и поведение разрешений мобильного аудио задокументированы.
- Известные ограничения задокументированы.
